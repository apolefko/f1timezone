Contact

Questions, corrections, or feedback about F1 Timezone? We'd genuinely like to hear it — especially if a session time looks wrong or a fact has gone stale.

Report an issue or suggest an improvement

The fastest way to reach the maintainer is through the site's public GitHub repository, where the schedule data and all pages live:

  • Open an issue on GitHub — for anything: a wrong race time, a broken link, a factual correction, or a feature idea. A free GitHub account is all you need, and issues are typically reviewed within a few days.
  • Browse the repository — the entire site is open source, so you can see exactly where the schedule data comes from (and even propose a fix directly).

What to include

For schedule corrections, please mention the race, the session, and the time you believe is correct with a source if you have one — that turns a back-and-forth into a five-minute fix. For anything else, plain description works fine.

A note on response times

F1 Timezone is an independent, one-person hobby project (see About), so responses aren't instant — but schedule corrections are treated as urgent, particularly in the week before a race.
